
# Java For Loop Program

## 📌 Description
This Java program demonstrates the use of `for` loops in Java.

It performs three operations:

1. Prints numbers from 0 to 10.
2. Prints even numbers from 2 to 20.
3. Calculates the sum of numbers from 1 to 10.

## 💻 Code Explanation

### 1. Print Numbers from 0 to 10
Uses a for loop to print numbers starting from 0 up to 10.

### 2. Print Even Numbers from 2 to 20
Uses a for loop with `j += 2` to print even numbers.

### 3. Sum of Numbers from 1 to 10
Uses a variable `sum` to calculate the total of numbers from 1 to 10.
